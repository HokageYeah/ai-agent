# 技能备注

本技能由 `skill-creator` 自动生成。

技能用途：
读取 API 日志文件，分析调用统计数据，生成结构化日报（结论/关键证据/下一步建议）。

核心功能：
- 按日期范围过滤日志（today/all/单日/区间）
- 统计日志级别分布（INFO/DEBUG/WARNING/ERROR）
- 汇总推理请求与工具调用关键指标
- 输出 text 或 json 两种格式

建议下一步：
1. 如日志格式变化，先调整 `scripts/analyze_api_log.py` 的解析正则。
2. 若需更细粒度 SLA 指标，可增加 P99、错误分类等字段。
3. 若需自动日报，建议由外层计划增加定时触发与 `file_write` 存档步骤。
